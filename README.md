Suwasewana is an AI-powered, full-stack Doctor Appointment Management System designed to digitalize healthcare services.  
The platform enables patients to book appointments, make secure online payments, and attend real-time video consultations, while doctors and admins efficiently manage schedules and system operations.

---

## 🚀 Features

- Role-Based Authentication (Admin, Doctor, Patient)
- Smart Doctor Appointment Scheduling
- Real-Time Video Consultations (ZegoCloud SDK)
- Secure Online Payments (PayHere Sandbox)
- Doctor Performance Badge System
- Real-Time Notifications & Alerts
- Cloud-Based Media Storage (Doctor & User Profiles)
- Responsive and Modern User Interface

---

## 🧠 AI-Assisted Capabilities

- Automated doctor ranking and badge allocation
- Appointment completion analytics
- Performance-based trust indicators
- Scalable architecture for predictive healthcare insights
